# Third-party protocol references

EF2SDK is MIT licensed and does not link third-party runtime libraries into
the EE ELF.

The MMCE protocol documentation/reference implementation used for
interoperability is from ps2-mmce/mmceman and is MIT licensed, copyright the
MMCE Authors.

Native PS2 memory-card packet behavior and MX4SIO SIO2/SD behavior were
cross-checked against public ps2dev sources as hardware/protocol references.
EF2SDK keeps its own source code, RPC protocol and public API.
